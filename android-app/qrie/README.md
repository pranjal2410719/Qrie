# Qrie Mobile Application (Flutter)

Flutter application for the **Qrie Student Learning Experience** (NCERT Classes 6–12).

---

## Directory Structure

```text
android-app/qrie/
├── lib/
│   └── main.dart          # Flutter application entrypoint
├── android/               # Native Android configuration & manifest
├── test/                  # Automated widget & unit tests
├── pubspec.yaml           # Dependencies and asset declarations
└── README.md
```

---

## Getting Started

```bash
# Get dependencies
flutter pub get

# Run on Android
flutter run
```
